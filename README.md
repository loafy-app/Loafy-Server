## 📋 Commit Convention
| type       | 의미               | 예시                                |
|------------|------------------|-----------------------------------|
| `init`     | 초기 설정            | `🎉 init: 프로젝트 초기 설정`              |
| `feat`     | 기능 추가            | `✨ feat: 로그인 API 구현`              |
| `fix`      | 버그 수정            | `🐛 fix: 비밀번호 검증 오류 수정`            |
| `refactor` | 동작 변화 없는 구조 개선   | `♻️ refactor: MemberService 책임 분리` |
| `chore`    | 설정, 의존성, 빌드 등    | `🔧 chore: Spring Security 의존성 추가` |
| `docs`     | 문서 수정            | `📝 docs: API 명세 추가`               |
| `test`     | 테스트 코드           | `✅ test: 회원가입 서비스 테스트 추가`         |
| `style`    | 포맷팅, import 정리 등 | `🎨 style: 코드 포맷 정리`               |
| `rename`   | 파일/패키지명 변경       | `✏️ rename: member 패키지 구조 변경`      |
| `remove`   | 불필요 코드/파일 삭제     | `🗑️ remove: 사용하지 않는 설정 파일 삭제`      |
